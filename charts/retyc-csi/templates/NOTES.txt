{{ .Chart.Name }} {{ .Chart.Version }} (driver {{ .Values.image.tag | default .Chart.AppVersion }}) is installed as release {{ .Release.Name }} in {{ .Release.Namespace }}.

  kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }}

The controller pods must be 3/3 Running, the node pods 2/2. A driver container that is not ready explains why on /readyz and in its logs.
Each staged volume runs a mount pod in this namespace, on the node that mounts it:

  kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/name=retyc-mount -L csi.retyc.com/pvc,csi.retyc.com/node

WARNING: the mount pods are privileged (RetycFS, mount propagation). The namespace {{ .Release.Namespace }} must allow it, e.g.
  kubectl label namespace {{ .Release.Namespace }} pod-security.kubernetes.io/enforce=privileged
(kube-system usually does.)
